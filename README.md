# AI Course Journal

This repository is my learning journal for the **LLM Engineering Program**. I'm using it to record what I learn as I go: notes, experiments, code, and reflections.

## About the Program

The **LLM Engineering Program** is a comprehensive, hands-on learning roadmap focused on enterprise AI engineering. Instead of just using surface-level AI tools, this program dives deep into building the actual infrastructure and systems around Large Language Models (LLMs). 

Key areas covered in the program include:
- **Transformer Foundations:** Understanding how models work under the hood, building small GPT models and tokenizers from scratch.
- **Agents, APIs, and MCP:** Building smart agents with tool use, structured outputs, and deploying Model Context Protocol (MCP) servers.
- **Orchestration & Retrieval (RAG):** Constructing hybrid search systems (combining vector and BM25 search) with proper ingestion, chunking, and bilingual (English-Hebrew) support.
- **Self-Hosting & Fine-Tuning:** Running open-weight models locally or on rented GPUs using Docker and vLLM, and adapting models using LoRA.
- **Evaluation & Security:** Setting up robust evaluation suites, LLM-as-a-judge frameworks, CI/CD regression gates, and layered security guardrails (OWASP GenAI top 10).
